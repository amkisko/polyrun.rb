# Release 2.2.9

## Decisions

Cut 2.2.9 from `main`. Ship `Polyrun::Benchmark::Pressure`, the coverage-merge pressure harness under `benchmarks/`, and the merge hot-path speedups proven in the pressure-cooker episode.

## Effects

VERSION is 2.2.9. CHANGELOG section dated 2026-11-07. PATH gem entries in `Gemfile.lock` and appraisal lockfiles point at 2.2.9. Gem package builds and verifies at 166400 compressed bytes across 190 packaged paths (source payload 763392 bytes). `lib/polyrun/benchmark/pressure.rb` and native merge changes ship in the gem; `benchmarks/` stays repo-local maintainer tooling.

## Next

Push `main`, then run `make release` to test, push the gem, tag `2.2.9`, and create the GitHub release. RubyGems still serves 2.2.8 until publish.
