# Release 3.0.0

## Decisions

Cut 3.0.0 for the hard-cut rename in RFC-0007: `Polyrun::RSpecSupport` and `Polyrun::MinitestSupport` replace `Polyrun::RSpec` and `Polyrun::Minitest`. Major bump because old constants and require paths are removed. Also ship the `::RSpec` qualification in `RspecJunit.install!`.

## Effects

VERSION is 3.0.0. CHANGELOG section dated 2026-11-12. PATH gem entries in `Gemfile.lock` and appraisal lockfiles point at 3.0.0. RFC 0007 is Stable.

## Next

Commit on the release branch, merge to `main`, then run `make release` to test, push the gem, tag `3.0.0`, and create the GitHub release. RubyGems still serves 2.2.9 until publish. Hosts must update requires and constants before upgrading.
