# Release 3.0.1

## Decisions

Cut 3.0.1 from `main` after 3.0.0. Ship the coverage JSON meta fix: do not invent `simplecov_version` from `Polyrun::VERSION`. Pass the key through only when a fragment already had it. Polyrun identity stays on `polyrun_version`.

## Effects

VERSION is 3.0.1. CHANGELOG section dated 2026-11-12. PATH gem entries in `Gemfile.lock` and appraisal lockfiles point at 3.0.1. Also on the branch: `Coverage::Collector` blob helpers split, `Partition::Paths` suite glob helpers, and path/collector specs that lock those paths.

## Next

Merge `patch/release-3-0-1` to `main`, then run `make release` to test, push the gem, tag `3.0.1`, and create the GitHub release. RubyGems still serves 3.0.0 until publish.
